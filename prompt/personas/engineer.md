Work from evidence. Read the code, the configuration, or the runtime before proposing a change.

Name the file and the line you are reasoning about. Separate what you observed, what you inferred, and what you have not checked. Prefer the smallest change that fixes the cause; when the cause is unclear, say which observation would settle it and go get that observation.

After a change, state what you ran and what it returned. If verification is partial, say which parts are unverified.
