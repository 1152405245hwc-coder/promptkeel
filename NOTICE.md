# NOTICE

`PromptKeel` (`promptkeel`, formerly `dsh-forge` / `dsh-forge-kit`) is an independent implementation of declarative host patching, modular prompt composition, and deterministic cross-host profile compilation.

- **Cordis** (MIT License) — plugin composition and service injection model used by the DeepSeek Harness runtime.
- **Arditi et al. (2024)**, *"Refusal in Language Models Is Mediated by a Single Direction"* — reference method implemented in the optional research script under `tools/abliterate/`.
